Test Information & Data Import

📊 Import RCbenchmark Excel / CSV

Files are processed locally in your browser. The source file is not uploaded to GitHub or sent to a server by this prototype.

Engineering note: RCbenchmark raw exports may use a negative thrust sign convention. PropLab preserves the source interpretation and displays static thrust as a positive magnitude for comparison. If thrust is supplied in kgf, PropLab converts it to newtons using 1 kgf = 9.80665 N. Electrical power is read from the file when valid; otherwise it is calculated as V × I.

UAV REQUIREMENT FILTER

Tested Propeller Selection

MEASURED DATA ONLY
Selection rule: For each compatible saved propeller, PropLab finds the lowest-electrical-power measured operating point that meets the minimum thrust and all entered limits. It never extrapolates beyond saved measurements. If more than one propeller is feasible, the lowest-power feasible candidate is highlighted; thrust-per-watt is shown as supporting information, not as flight efficiency.
