# AeroMRO

AeroMRO is an integrated web-based aircraft maintenance workflow
and AI-assisted training platform developed as part of
AVT 4902 – Graduation Project I.

## Main Modules

### Maintenance Workspace
- Simulated job cards
- Mechanic task execution
- Evidence submission
- QA inspection
- Audit trail

### Training Academy
- Interactive aircraft systems learning
- Troubleshooting scenarios
- Quizzes and assessments
- AI-assisted educational support

> This project is intended for education and simulation only.
> It does not replace approved aircraft maintenance manuals,
> procedures, regulatory requirements, or authorized maintenance data.
